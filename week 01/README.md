# Week 01 - Exploratory Data Analysis (EDA) Basics

## 📚 Overview

This folder contains materials for Week 01 of the Foundations of Machine Learning (FOML) course, focusing on the fundamentals of Exploratory Data Analysis (EDA) using Python.

## 📁 Contents

- **`eda-basics.ipynb`** - Jupyter notebook covering basic EDA techniques and data visualization
- **`ChurnModelling.csv`** - Customer churn dataset used for analysis and demonstrations
- **`requirements.txt`** - Python package dependencies required to run the notebook

## 🎯 Learning Objectives

- Understanding the basics of Exploratory Data Analysis
- Loading and inspecting datasets using Pandas
- Performing basic data analysis and statistics
- Visualizing data distributions and patterns
- Working with real-world datasets (customer churn data)

## 🛠️ Prerequisites

### Required Software
- Python 3.7 or higher
- Jupyter Notebook or JupyterLab

### Required Libraries
All necessary libraries are listed in `requirements.txt`:
- `numpy` - Numerical computing
- `pandas` - Data manipulation and analysis
- `plotly` - Interactive visualizations
- `matplotlib` - Static plotting
- `seaborn` - Statistical data visualization
- `scikit-learn` - Machine learning tools

## 🚀 Getting Started


## 📊 Dataset Information

### ChurnModelling.csv
This dataset contains customer information for a bank, including:
- Customer demographics
- Account information
- Customer behavior patterns
- Churn status (whether the customer left the bank)

The dataset is used to demonstrate various EDA techniques and prepare for future machine learning tasks related to customer churn prediction.

## 📝 Topics Covered

The `eda-basics.ipynb` notebook covers:

1. **Importing Libraries** - Setting up the Python environment with essential data science libraries
2. **Loading Data** - Reading CSV files using Pandas
3. **Basic Information** - Inspecting dataset structure, data types, and summary statistics
4. **Data Visualization** - Creating plots to understand data distributions
5. **Distribution Analysis** - Analyzing the 'Exited' column and other features

## 💡 Tips for Learning

- Run each cell in the notebook sequentially to understand the flow
- Experiment with the code by modifying parameters and creating your own visualizations
- Try to understand the insights gained from each visualization
- Take notes on patterns and anomalies you observe in the data
